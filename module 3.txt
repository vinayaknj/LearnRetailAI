Module 3: Inventory and Fulfillment Domain Mastery
Purpose

Inventory is the lifeblood of retail operations.

Customers buy products, but retailers manage inventory.

A retailer can survive a temporary POS issue. It cannot survive prolonged inventory inaccuracy.

Poor inventory management causes:

Plain Text

Stock-Outs
Excess Inventory

This module teaches how inventory moves, changes, gets reconciled, and supports omnichannel retail operations.

Chapter 2: Inventory States

Inventory exists in different business states.

Understanding these states is critical.

On-Hand Inventory

Physical inventory present at location.

Example:

Plain Text
Store 100
 
Milk = 50 Units

Inventory physically exists.

Available-to-Sell (ATS)

Inventory available for purchase.

Formula:

Plain Text
ATS = On-Hand - Reserved

Example:

Plain Text
On-Hand = 50
 
Reserved = 10
 
ATS = 40

Customers can only buy from ATS.

Reserved Inventory

Inventory committed to orders.

Example:

Plain Text
BOPIS Order
 
Customer Ordered TV
 
TV Removed From ATS

Until pickup occurs.

In-Transit Inventory

Inventory moving between locations.

Example:

Plain Text
Warehouse → Store
 
500 Units

Not yet available for sale.

Damaged Inventory

Inventory unsuitable for sale.

Examples:

Plain Text
Broken
 
Expired
 
Water Damage
 
Packaging Damage

Must be segregated from sellable stock.

Return Inventory

Products returned by customers.

Possible outcomes:

Plain Text
Restock
 
Refurbish
 
Destroy
 
Return To Vendor

Chapter 3: Inventory Movements

Inventory changes through events.

Every inventory adjustment should have a business reason.

Receiving

Store receives inventory.

Example:

Plain Text
PO: 12345
 
Expected: 100 Cases
 
Received: 100 Cases

Inventory increases.

Sales

Customer buys product.

Example:

Plain Text
Milk: 50
 
Customer Buys 2
 
Inventory = 48

Inventory decreases.

Returns

Customer returns item.

Example:

Plain Text
Laptop Returned

Inventory usually increases.

Transfers

Inventory moved between locations.

Example:

Plain Text
Store 100 → Store 120
 
Inventory:
Store 100 = -10
 
Store 120 = +10
Adjustments

Manual changes.

Examples:

Plain Text
Damage
 
Theft
 
Audits
 
Corrections

Should be highly controlled.

Chapter 11: Stock Drift and Reconciliation

Critical topic for support engineers.

What is Stock Drift?

Inventory differs between systems.

Example:

Plain Text
POS = 100
 
IMS = 95

Mismatch exists.

Common Causes
Sale Upload Failure

POS sold item.

Inventory system never updated.

Duplicate Messages

Inventory deducted twice.

Transfer Errors

Transfer shipped but not received.

Manual Adjustments

Improper inventory changes.

Offline Stores

Delayed synchronization.
